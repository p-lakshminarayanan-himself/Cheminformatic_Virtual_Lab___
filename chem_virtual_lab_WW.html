Theory

SMILES

Simplified Molecular Input Line Entry System writes a molecule as text. Atoms are element symbols (lowercase c, n = aromatic), = and # are double and triple bonds, branches go in ( ), and rings use matching digits. Examples: ethanol CCO, benzene c1ccccc1.

Descriptors

Descriptors turn a structure into numbers: molecular weight, LogP (lipophilicity), TPSA (polar surface area), hydrogen-bond donors and acceptors, rotatable bonds and ring counts.

Lipinski's Rule of 5

A molecule is likely orally active if MW ≤ 500, LogP ≤ 5, H-bond donors ≤ 5 and H-bond acceptors ≤ 10. More than one violation suggests poor absorption.

Fingerprints and similarity

A Morgan (ECFP4) fingerprint is a bit vector of substructures. Tanimoto similarity = shared bits ÷ bits set in either molecule, from 0 (unrelated) to 1 (identical).

Structure–property relationships

Polar groups raise TPSA and lower LogP; larger carbon skeletons raise MW and LogP. Comparing molecules reveals these trends, which QSAR models use for prediction.
